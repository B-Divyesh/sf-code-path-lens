How Code Path Lens works

It builds a small review slice from parsed local source. It does not claim to reproduce runtime behavior.

  1. Choose a symbol

    Start with the function or method under review.

  2. Set a bound

    Keep caller and callee steps within a stated depth and node limit.

  3. Open the evidence

    Review source excerpts, links, types, boundaries, and unresolved calls.

Run the CLI on a local repository

Use the bundled demo first, then trace a symbol in a Rust, TypeScript, JavaScript, Python, or Go repository.

cargo install --path .
code-path-lens demo

What the analysis does not do

It is bounded static analysis. Dynamic dispatch, reflection, generated code, and runtime configuration can change the actual path.

The free CLI has no account, cloud index, telemetry, or source upload. It respects .gitignore and skips common generated and vendor directories by default.
