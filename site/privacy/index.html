Policy / effective 27 August 2026

Privacy, plainly.

Code Path Lens is designed so your source code stays on your machine. The CLI parses local files and writes local output. It includes no analytics, crash reporter, remote index, or telemetry.

Website storage

If you return from checkout or paste a license, the website stores the token and a time-stamped verification result in your browser’s local storage. This lets the page remember your unlock and limits verification to at most once per day. Remove it at any time through your browser’s site-data controls.

License verification

The website and paid CLI limits send only the license token to the Sociobot billing API. They do not send source code, file names, graph results, repository metadata, or command arguments. Sociobot/Dodo, the merchant of record, processes checkout details under its own payment records and legal obligations.

Network and offline use

The free CLI works without a network. The site uses a service worker to cache its public shell for offline reading. It does not use third-party fonts, scripts, advertising, or behavioral analytics.

Contact

For privacy requests, use the support address included in your Sociobot purchase receipt or open an issue in the public repository. We retain no product account database to search.
