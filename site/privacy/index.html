Privacy for local code analysis

Code Path Lens parses local files and writes local output. The free CLI does not upload source code, file names, graph results, repository metadata, or command arguments.

Sample demo storage

The browser sample writes one temporary marker in its own local-storage namespace: demo:code-path-lens:session. Reset demo and Start for real delete that marker. The sample does not read or write your real product data.

Website requests

The public site has no analytics, advertising, crash reporter, third-party fonts, or third-party scripts. It uses a service worker to cache its own public pages for offline reading.

Contact

For a privacy question, open an issue in the public repository. Code Path Lens has no product account database.
