Terms for bounded static analysis

Code Path Lens is open-source software provided under the MIT License. These terms cover the hosted documentation and bundled sample.

Review linked source before relying on output

The tool makes a bounded static approximation. Dynamic dispatch, reflection, macros, generated code, runtime configuration, and unsupported syntax can change the actual execution path. Review the linked source before using a result for security, safety, or production decisions.

Free distribution

The current public release provides the free CLI and its HTML, JSON, and DOT outputs. Core export, accessibility, and safety behavior are not gated.
